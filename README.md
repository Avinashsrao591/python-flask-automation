
# Python Flask Automation Framework

An automation framework built with Python, Flask, Pytest,
Selenium WebDriver, and Requests.

## Features

- Flask dashboard for launching automation jobs
- Background job execution
- Smoke and regression test suites
- REST API automation
- Selenium UI automation with Chrome
- HTML test reports using pytest-html
- Job status tracking and execution statistics

## Technology Stack

- Python 3.11+
- Flask
- Pytest
- Selenium WebDriver
- Requests
- pytest-html
- Git

## Setup on Windows

Clone the repository or open the project directory.

Create a virtual environment:

```powershell
python -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Run the Application

Start Flask:

```powershell
python app.py
```

```Open the dashboard:

https://127.0.0.1:5000/

## Run Tests

Run the complete suite:

```powershell
python -m pytest -v
```

Run individual suites:

```powershell
python -m pytest automation_tests/smoke -v
python -m pytest automation_tests/regression -v
python -m pytest automation_tests/api -v
python -m pytest automation_tests/ui -v
```

The Flask server must be running when executing API and UI tests.

## Reports

HTML reports generated by submitted automation jobs are stored
in the reports directory.
